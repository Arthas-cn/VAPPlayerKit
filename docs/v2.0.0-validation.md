纯 SPM 的工具宿主测试不能在真机运行，因此 SwiftExample 新增 `SwiftExampleTests` 应用宿主，复用相同测试源码与正式 fixture。没有为绕过环境问题删测试、改素材或关闭并发检查。真机签名使用维护者本地配置，不写入仓库。

```sh
xcodebuild -project Examples/SwiftExample/SwiftExample.xcodeproj \
  -scheme SwiftExample -destination 'platform=iOS,id=<DEVICE_UDID>' \
  -only-testing:SwiftExampleTests test

xcodebuild -project Examples/SwiftExample/SwiftExample.xcodeproj \
  -scheme SwiftExample -destination 'platform=iOS,id=<DEVICE_UDID>' \
  -only-testing:SwiftExampleUITests/SwiftExampleUITests/testEveryBundledFixtureOnDevice \
  -only-testing:SwiftExampleUITests/SwiftExampleUITests/testCatalogCountMatchesRowsAndPlaybackLifecycle \
  -only-testing:SwiftExampleUITests/SwiftExampleUITests/testSwiftUIPackedAlphaPlaybackControls test
```

GPU 用例直接执行正式 Metal 函数，检查四个方向的任意颜色/Alpha 矩形、黑/灰/白 Alpha 和预乘输出。音频故障、定位、取消与排空使用可控驱动验证；这些逻辑断言不等于已人工听验扬声器声音。

已知边界：拼接透明视频必须显式给出布局，不支持原生 HEVC Alpha 或双文件透明视频；动态 provider 不合作退出时排空继续等待；SwiftUI 终态不提供文件使用权归还屏障，需要精确归还时通过 UIKit `clearAndWait()` 接入。性能对照和 Instruments 长时间跟踪不属于本次通过记录。
